# NextStep Physio

SaaS multi-tenant de agentes IA para clínicas de rehabilitación física y medicina deportiva.

Adaptado a partir del frame [Real-Estate-Multi-AI-Agent-SaaS](https://github.com/jukaben32/Real-Estate-Multi-AI-Agent-SaaS), siguiendo el mismo patrón usado para [EstetiCall](https://github.com/jukaben32/Esteticall) y [NailAtelier](https://github.com/jukaben32/NailAtelier).

## Stack

- Next.js, TypeScript, Tailwind CSS
- Supabase (DB, auth, storage)
- OpenAI Realtime (agente de voz)
- Stripe (suscripciones)

## Dirección de marca

Clínico confiable + energía de recuperación: azul-verde profundo (confianza médica) + acento coral (movimiento, optimismo). Paleta y tokens en `src/styles/globals.css` y `tailwind.config.ts`.
